:::caution[Avant-première]
Llooma n'est pas fait pour la production. Attendez-vous à des changements cassants, des
fonctionnalités inachevées et des aspérités. Le travail récent a porté sur le mode serveur ; le
mode local peut présenter des incohérences qui demandent encore une passe de vérification.
:::
