<Card title="Two ways to run it" icon="laptop">
**Local** keeps everything in your browser, with your own provider keys. **Server** signs users in, stores their data per account, and keeps the API keys where a browser can never read them.

[Choose a mode →](/llooma/guides/running-modes/)
</Card>

<Card title="Bring your own models" icon="puzzle">
Ollama, OpenAI, Claude, Infomaniak and anything OpenAI-compatible. Several at once, each with its own label and colour, so you always know which endpoint is about to be billed.

[See the providers →](/llooma/reference/providers/)
</Card>

<Card title="Documents, read in the tab" icon="open-book">
A PDF, a spreadsheet, a Word file. Parsed in your browser and never uploaded, in server mode too. Optional OCR for scans, and a vision fallback when a page is a picture of words.

[How it works →](/llooma/features/documents/)
</Card>

<Card title="Conversations that keep fitting" icon="seti:clock">
`/compact` replaces a long history with a structured summary so it still fits in the window. Nothing is deleted, and one click puts it all back.

[Read about compaction →](/llooma/features/compaction/)
</Card>
</CardGrid>
